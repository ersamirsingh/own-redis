# PyRedis Operational Dashboard

Production web application for PyRedis built with Next.js 15, TypeScript, and Tailwind CSS.

## Features
- Full authentication with JWT & RBAC (Admin, Operator, Developer, ReadOnly).
- Operational Data Console with type-aware key editors.
- In-browser Monaco Command Console.
- Real-time telemetry dashboards (Memory, Latency, Hit Ratio, TTL).
- Trace Explorer waterfall analyzer.
- Google Gemini AI diagnostics and assistant.

## Development
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
